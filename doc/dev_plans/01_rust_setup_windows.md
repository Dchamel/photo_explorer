# Установка Rust на Windows 11 (для VS Code)

> Инструкция для заказчика, который не знаком с Rust.
> После установки у нас появятся команды `rustc`, `cargo` и расширение в VS Code.

---

## Коротко о Rust (что нужно знать)

- **Rust** — компилируемый язык: быстрый как C++, но безопасный (не падает из-за ошибок памяти).
- **Cargo** — «всё в одном»: менеджер пакетов + сборщик + запускатель тестов.
- **Crate** (крейт) — внешняя библиотека. Берём с сайта [crates.io](https://crates.io).
- **`Cargo.toml`** — манифест проекта: имя, версия, список зависимостей.
- **Модуль (`mod`)** — единица организации кода. Структура папок = структура модулей.

### Главные команды Cargo
| Команда | Что делает |
|---------|-----------|
| `cargo build` | Собрать проект |
| `cargo run` | Собрать и запустить |
| `cargo test` | Запустить все тесты |
| `cargo fmt` | Автоформатирование кода |
| `cargo clippy` | Линтер (находит потенциальные ошибки и плохой стиль) |

## Шаг 1. Установить компилятор C++ (обязательно для Windows)

Rust на Windows использует компоновщик от Microsoft. Нужны **Visual Studio Build Tools**.

1. Скачать: [https://visualstudio.microsoft.com/visual-cpp-build-tools/](https://visualstudio.microsoft.com/visual-cpp-build-tools/)
2. Запустить установщик.
3. Выбрать компонент **«Desktop development with C++»**.
4. Установить.

> Если пропустить этот шаг — установщик Rust сам предложит его поставить.

---

## Шаг 2. Установить Rust через rustup

1. Открыть сайт: [https://rustup.rs](https://rustup.rs)
2. Скачать `rustup-init.exe` и запустить.
3. В консоли выбрать вариант **`1) Proceed with standard installation`** (нажать Enter).
4. Дождаться окончания.
5. **Перезапустить терминал** (и VS Code), чтобы команды стали доступны.

### Проверка установки
Открыть терминал (в VS Code: `Terminal → New Terminal`) и выполнить:

```powershell
rustc --version
cargo --version
```

Должны увидеть версии, например:
```
rustc 1.xx.0
cargo 1.xx.0
```

---

## Шаг 3. Настроить VS Code

1. Открыть VS Code → вкладка **Extensions** (Ctrl+Shift+X).
2. Установить расширение **`rust-analyzer`** (официальное, от rust-lang).
   - Даёт автодополнение, подсветку ошибок прямо в редакторе, подсказки типов.
3. (Рекомендуется) Установить **`Even Better TOML`** — для подсветки файла `Cargo.toml`.
4. (Опционально) **`CodeLLDB`** — для отладки.

---

## Шаг 4. Установить компоненты для нашего проекта

Выполнить в терминале (нужны для CI и качества кода):

```powershell
rustup component add rustfmt
rustup component add clippy
```
